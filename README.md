# 🎓 Learning with Fun

A modern, interactive platform for learning and training with various practice modes. Perfect for beginners and advanced users!

## 🌟 Features

### ⌨️ Touch Typing Master - Keyboard Training System
- **📖 Basics**: Learn the home row position and finger placement
- **🎯 Practice**: Train with focused key combinations
- **💬 Words**: Type commonly used English words
- **⏱️ 1-Min Test**: Test your WPM (Words Per Minute)
- **🤖 Bot Race**: Race against AI opponents
- **👥 Duo Mode**: Multiplayer games with friends

**Features:**
- ✅ Real-time statistics (WPM, Accuracy, Errors)
- ✅ Visual keyboard highlighting
- ✅ Sound effects
- ✅ Confetti animation on success
- ✅ Streak counter with Local Storage

### 📝 To-Do List
- ✅ Add and manage tasks
- ✅ Mark tasks as completed
- ✅ Filter options (All, Active, Completed)
- ✅ Live statistics
- ✅ Full persistence with Local Storage

**Features:**
- ✅ Automatic saving in browser
- ✅ Keyboard support (Enter to add)
- ✅ Task history with dates
- ✅ Quick delete completed tasks

## 🚀 Quick Start

1. Open the website in your browser
2. Choose a training mode
3. Start typing!
4. Use the To-Do List for your tasks

## 💡 Training Tips

1. **Start with Basics**: Begin with the "Basics" tab
2. **Regular Training**: Train daily for best results
3. **Focus on Accuracy**: Type accurately first, then fast
4. **Build Streaks**: Use the streak counter as motivation
5. **Bot Races**: Test yourself against different difficulties

## 🎯 Goals

- ⚡ Increase WPM (Target: 60+ WPM)
- 🎯 Improve accuracy (Target: 98%+)
- 🏆 Win bot races
- 🔥 Build long streaks

## 🔐 Privacy

- All data is stored **locally in your browser**
- No data transmission to external servers
- Your data remains private and secure

## 🛠️ Development

Want to extend the app? It's easy to modify:

- **Change texts**: Modify the `sampleTexts` object in `index.html`
- **Adjust layout**: Modify Tailwind CSS classes
- **Add new modes**: Add new functions to the `<script>` block
